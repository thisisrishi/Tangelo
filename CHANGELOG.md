# Changelog

## 1.1.0 — 2026-10-18

**Tangelo for Windows** — the full feature set, native on Windows 10 and 11.

- Conversion, tools and actions wheels: tap Shift, Ctrl or Alt while dragging files in File Explorer
- 45+ formats and 30+ tools, the same as the Mac app (HEIC is input-only on Windows)
- Floats with Explorer thumbnails, multi-file drag out, preview (Space) and restore on restart
- Tray panel with drop zone and Explorer-selection mode; "Tangelo…" in the File Explorer right-click menu
- Windows share sheet, Windows Terminal, Windows OCR and face detection, on-device background removal
- Per-user installer (no admin rights) and a portable zip, both self-contained with ffmpeg bundled
- 93-check engine self-test runs on every build (`Tangelo.exe --selftest`)

macOS: no functional changes in this release.

## 1.0.0 — 2026-10-18

First public release.

- Conversion, tools and actions wheels opened by tapping a modifier while dragging files
- 45+ formats across images, video, audio, documents, PDF, spreadsheets, presentations, subtitles and archives
- 30+ tools: compress, adjust, annotate, frame, crop, resize, remove background, OCR, redact, collage, QR,
  trim, crop, speed, mute, join, split, snapshots, GIF, normalize, channels, bleep, visualizer,
  PDF make/merge/split/organize, extract, metadata, batch rename
- Floats: floating file shelves with Quick Look, multi-file drag out and restore on relaunch
- History with Undo, configurable shortcuts and output location, launch at login
- Universal binary (Apple Silicon and Intel), macOS 14+
